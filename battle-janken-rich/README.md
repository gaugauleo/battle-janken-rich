# バトルじゃんけん

## ① 制作アプリのタイトル
バトルじゃんけん

## ② 制作アプリの説明
HP制（どちらかが3回負けたら終了）のバトル形式で、CPUと対戦するじゃんけんゲームです。

## ③ 工夫した点・こだわった点
何回負けたら終了、というルールを設けるにあたって、回数をHPとしてハートで表示し、よりバトル感を感じられるようにしました。

じゃんけんに勝ったとき・負けたときで、キャラクターの画像が喜びや悔しさの表情に切り替わるようにしました。

マウスを重ねたときの演出にもこだわりました。

## ④ 難しかった点・次回トライしたいこと
JavaScriptとjQueryを使った、勝敗判定やHP管理、画像の切り替わりなどの処理を理解するのが難しかったです。

### 次回トライしたいこと
やはりまだまだAIに頼りきりな結果になってしまったので、JavaScriptの処理を一から自分で組み立てられるようになれるよう頑張ります。

## ⑤ 感想
自分の作りたいものが形になって動くことにとても感動しました。
JavaScriptすごい...！！

どういった処理でどのような動きになるのか、まだ大まかにしか理解できていないため、みっちり勉強が必要だと思いました。

今回はAI生成画像をたくさん使用したのですが、画像生成の機能も意外と思った通りにいかずなかなか苦戦しました。
「どういった指示の出し方をすれば希望通りに生成してくれる？」と、指示の出し方をAIに指示してもらう、ということをすると意外とうまくいきました。
